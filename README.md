# Christoph Schneider — Portfolio

Static site. Unzip the contents of this folder into the root of
`Stufj/Stufj.github.io` and push to `master`.

- `index.html` redirects to `Home.dc.html`
- `.nojekyll` keeps GitHub Pages from filtering files
- `support.js` must stay next to the pages
- `_ds/` holds the design-system stylesheet and bundle
